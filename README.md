# Biblioteca - Sistema de Gerenciamento

Este projeto é um sistema de gerenciamento de biblioteca desenvolvido em C# com .NET 8, focado em operações como cadastro, consulta e controle de livros, autores e usuários. O sistema foi pensado para ser modular, didático e de fácil manutenção, ideal para fins acadêmicos e demonstração de habilidades em desenvolvimento backend.

## Autor

Luan Eduardo Treuke

## Tecnologias Utilizadas
- **C#**
- **.NET 8**
- **Programação Orientada a Objetos**

## Descrição Geral
O projeto segue boas práticas de desenvolvimento em C#, com separação de entidades, interfaces e lógica de negócio. A estrutura modular facilita a manutenção e expansão do sistema, sendo ideal para aprendizado e demonstração de domínio em backend .NET.

## Diferenciais do Projeto
- Estrutura de código limpa, modular e orientada a objetos.
- Pronto para expansão com novas funcionalidades.
- Ideal para estudos, portfólio e demonstração de habilidades em C# e .NET.

## Como Executar
1. Abra a solução `Biblioteca.sln` no Visual Studio ou editor compatível.
2. Compile o projeto.
3. Execute a aplicação.
